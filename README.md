# Movie Collection API

A RESTful API built with FastAPI and SQLite for managing a movie collection. Includes Pydantic data validation and persistent database storage.

## Features
- Full CRUD operations (Create, Read, Update, Delete)
- SQLite database persistence
- Request validation with Pydantic
- Sorting functionality by duration or rating
